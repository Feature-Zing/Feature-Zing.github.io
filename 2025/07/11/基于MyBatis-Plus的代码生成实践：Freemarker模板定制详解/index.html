基于 MyBatis-Plus 的代码生成实践：Freemarker 模板定制详解

开发中我们使用mybatis-plus框架作为持久层框架，mybatis-plus是在mybatis的基础上进行增强，简化了开发，提高了开发效率，其中我们就使用mybatis-plus提供的代码生成器来生成我们的mapper、entity、service、serviceImpl、controller 方便我们快速搭建一个项目基本框架，提升开发效率。

Mybatis-plus的提供的代码生成器，支持多种模板引擎自动生成代码，通过mybatis-plus 源码可知支持四种模板引擎，分别是：Freemarker、Velocity、Beetl、Enjoy ，四种模板引擎，并且支持自定义模板引擎。如下所示：

  1. FreemarkerTemplateEngine
  2. VelocityTemplateEngine
  3. EnjoyTemplateEngine
  4. BeetlTemplateEngine
  5. 自定义实现模板引擎

本次主要通过FreemarkerTemplateEngine 来实现自动代码生成并且添加自定义模板相关实现代码生成。

模板自动使用场景有：

  1. 拓展模板，如生成VO，DTO类模板
  2. 修改模板，如entity，mapper相关模板修改。
  3. 数据库表或者字段名称映射，对表名或者字段名进行加密操作，比如使用t001，f001…fn，不使用字段英文单词进行加解密

自定义模板生成

mybaits-plus的模板生成为我们提供了五种基本的模板，但是在实际开发中需要生成一些VO，DTO等类，这时候需要我们自己定义一个模板进行自动生成，减少编码，方便我们在开发中使用，也可以结合mapstruct生成基本的Convert，方便进行转换操作。本次通过生成一个简单的VO来进行演示生成。

准备entityVO.java.ftl 代码模板

模板命名为entityVO.java.ftl，代码如下，根据freemarker语法进行模板的编写，具体的FreeMarker语法可以查看官网

package ${package.Entity}.vo;
<#if springdoc>
import io.swagger.v3.oas.annotations.media.Schema;
<#elseif swagger>
import io.swagger.annotations.ApiModel;
import io.swagger.annotations.ApiModelProperty;
</#if>
<#if entityLombokModel>
import lombok.Getter;
import lombok.Setter;
<#if chainModel>
import lombok.experimental.Accessors;
</#if>
</#if>

/**
* ${entity} VO 对象
*
* @author ${author}
* @since ${date}
*/
<#if entityLombokModel>
@Getter
@Setter
<#if chainModel>
@Accessors(chain = true)
</#if>
</#if>
<#if springdoc>
@Schema(name = "${entity}", description = "${table.comment!}")
<#elseif swagger>
@ApiModel(value = "${entity}VO对象", description = "${table.comment!}")
</#if>
public class ${entity}VO {

<#-- ----------  BEGIN 字段循环遍历  ---------->
<#list table.fields as field>
    <#if field.comment!?length gt 0>
        <#if springdoc>
            @Schema(description = "${field.comment}")
        <#elseif swagger>
            @ApiModelProperty("${field.comment}")
        <#else>
            /**
            * ${field.comment}
            */
        </#if>
    </#if>
    private ${field.propertyType} ${field.propertyName};

</#list>
<#------------  END 字段循环遍历  ---------->
<#if !entityLombokModel>
    <#list table.fields as field>
        <#if field.propertyType == "boolean">
            <#assign getprefix="is"/>
        <#else>
            <#assign getprefix="get"/>
        </#if>

    public ${field.propertyType} ${getprefix}${field.capitalName}() {
        return this.${field.propertyName};
    }

        <#if chainModel>
    public ${entity}VO set${field.capitalName}(${field.propertyType} ${field.propertyName}) {
        <#else>
    public void set${field.capitalName}(${field.propertyType} ${field.propertyName}) {
        </#if>
        this.${field.propertyName} = ${field.propertyName};
        <#if chainModel>
        return this;
        </#if>
    }
    </#list>

    @Override
    public String toString() {
        return "${entity}{" +
    <#list table.fields as field>
        <#if field_index==0>
            "${field.propertyName} = " + ${field.propertyName} +
        <#else>
            ", ${field.propertyName} = " + ${field.propertyName} +
        </#if>
    </#list>
         "}";
    }
</#if>
}

generator 生成器配置

public class Generator {

    private static final String url = "jdbc:mysql://192.168.0.105:3306/code_generator?serverTimezone=UTC&useUnicode=true&characterEncoding=utf-8&useSSL=false";
    private static final String username = "root";
    private static final String password = "Ly123456!";
    private static final String userDir = System.getProperty("user.dir");
    private static final String parent = "com.future.mybatisplus";


    public static void main(String[] args) {
        final String currentProjectPath = currentProjectPath();
        String resourceMapperPath = currentProjectPath + "\\src\\main\\resources\\mapper";
        String outputPath = currentProjectPath + "\\src\\main\\java";
        FastAutoGenerator.create(url, username, password)
                .globalConfig(builder -> builder
                        .author("Liy")
                        .outputDir(outputPath)
                        // 不打开输出目录
                        .disableOpenDir()
                        .commentDate(LocalDateTimeUtil.format(LocalDateTime.now(), DatePattern.NORM_DATE_PATTERN))
                )
                .packageConfig(builder -> builder
                        .parent(parent)
                        .entity("entity")
                        .mapper("mapper")
                        .controller("controller")
                        .service("service")
                        .serviceImpl("service.impl")
                        .pathInfo(Collections.singletonMap(OutputFile.xml, resourceMapperPath))
                )
                .strategyConfig(builder -> builder
                        .entityBuilder()
                        .enableFileOverride()
                        .nameConvert(new NameConvert())
                        .idType(IdType.AUTO)
                        .enableColumnConstant()
                        .enableLombok()
                        .enableTableFieldAnnotation()
                        .addTableFills(new Column("create_time", FieldFill.INSERT))
                        .addTableFills(new Column("update_time", FieldFill.INSERT_UPDATE))
                        .serviceBuilder()
                        .enableFileOverride()
                        .controllerBuilder()
                        .enableRestStyle()
                        .enableFileOverride()
                        .mapperBuilder()
                        .enableFileOverride()
                )
                .injectionConfig(builder -> {
                    Map<String, Object> objectMap = new HashMap<>();
                    objectMap.put("customor", new Author("6"));
                    builder.customMap(objectMap)
                            // 自定义模板地址
                            .customFile(new CustomFile.Builder()
                                    // 不能为空，则生成文件名称为空
                                    .fileName("")
                                    .formatNameFunction(tableInfo -> {
                                        return tableInfo.getEntityName() + "VO.java";
                                    })
                                    .templatePath("templates/entityVO.java.ftl")
                                    .packageName("entity.vo")
                                    .enableFileOverride()
                                    .build()
                            );
                    builder.customMap(objectMap)
                            // 自定义模板地址
                            .customFile(new CustomFile.Builder()
                                    // 不能为空，则生成文件名称为空
                                    .fileName("")
                                    .formatNameFunction(tableInfo -> {
                                        return tableInfo.getEntityName() + "DTO.java";
                                    })
                                    .templatePath("templates/entityDTO.java.ftl")
                                    .packageName("dto")
                                    .enableFileOverride()
                                    .build()
                            );
                })
                .templateEngine(new FreemarkerTemplateEngine())
                .execute();
    }


    public static String currentProjectPath() {
        String path = Thread.currentThread().getContextClassLoader().getResource("").getPath();
        // 去除前后空格
        path = path.substring(1);
        final int indexOf = path.indexOf("target");
        if (indexOf > -1) {
            return path.substring(0, indexOf);
        }
        return path;
    }


}

核心逻辑是通过injectionConfig配置自定义模板地址以及设置对应的变量。配置对应模板的位置以及对应生成文件名称，是否重写，核心代码为：

// 定义模板中使用到的变量
Map<String, Object> objectMap = new HashMap<>();
objectMap.put("customor", new Author("6"));
builder.customMap(objectMap)
    // 自定义模板地址
    .customFile(new CustomFile.Builder()
                // 不能为空，否则生成文件失败
                .fileName("")
                .formatNameFunction(tableInfo -> {
                    return tableInfo.getEntityName() + "VO.java";
                })
                .templatePath("templates/entityVO.java.ftl")
                .packageName("entity.vo")
                .enableFileOverride()
                .build()
               )

点击生成后就可以生成VO类对象，提供编码使用，同时支持lombok注解及swagger注解，通过generator的策略进行设置。

变量注入

自定义代码模板后，如果在模板中引入自定义变量并且使用，我们需要代码生成器流程注入我们自定义的变量值。方式有两种，一种是通过injectionConfig 设置ObjectMap、一种是通过自定义重写模板重写getObjectMap方法。两种方式都是通过ObjectMap设置属性值进入。

方式一：通过injectionConfig

Map<String, Object> objectMap = new HashMap<>();
objectMap.put("customor", new Author("6"));

需要在生成设置代码生成器的时候，通过injectionConfig进行设置即可，可以是对象，基本数据类型等，前面通过自定义VO模板生成注入对象使用的就是上面这种方式。

方式二：重写对应模板的getObjectMap方法

本文使用的是FreemarkerTemplateEngine模板引擎，需要自定义一个类继承当前模板引擎，然后重写对应方法即可。

@Slf4j
public class CustomerFreemarkerTemplateEngine extends FreemarkerTemplateEngine {

    /**
     * 设置自定义变量，注入模板中使用
     *
     * @param config    配置信息
     * @param tableInfo 表信息对象
     * @return
     */
    @Override
    public @NotNull Map<String, Object> getObjectMap(@NotNull ConfigBuilder config, @NotNull TableInfo tableInfo) {
        Map<String, Object> objectMap = super.getObjectMap(config, tableInfo);
        objectMap.put("customor", new Author("5"));
        return objectMap;

    }
}
